# 技术发现与经济变革

> 范围：默认 `920-950年`
> 重点：交通、军备、冶炼、金融、税制、盐铁、漕运、商贸网络

## 建议结构

- 主题
- 变化内容
- 涉及区域
- 对政权 / 节镇 / 民间的影响
- 可转化为小说冲突或道具的方向

## 920-950 关键技术与经济变革线索

### 1. 北运与南运之间的新联通
- 主题：后唐至后晋阶段，北方漕运与南方盐铁、粮食的衔接重新加密，河道修整与闸口调度变得更重要。
- 变化内容：人工河段与旧渠整修，使华北军需运输比单纯依赖陆路更稳定，也让“谁掌闸、谁掌转运”成为新的权力节点。
- 涉及区域：河北、河东、洛阳、开封一线。
- 对政权 / 节镇 / 民间的影响：朝廷和节镇都更重视漕运节点，沿线百姓则承受徭役、抽粮、截留与护运差役。
- 可转化方向：闸钥、运粮文书、盐船暗号、夜间改道，都可以直接变成谍报、截杀或军需危机桥段。

### 2. 火药兵器的前奏
- 主题：五代时期火油、火箭、火矛之类的早期火器已经开始在局部战场出现。
- 变化内容：它们还不是决定胜负的主流武器，但已经足够改写夜袭、水战、守城和惊扰战马的方式。
- 涉及区域：江南水道、边地戍堡、西北走廊。
- 对政权 / 节镇 / 民间的影响：军镇会争夺硝石、硫黄、油料与工匠；民间则开始把配方、油料与仓储安全当作新的风险来源。
- 可转化方向：一支火箭、半瓶火油、一个会调配引火药的匠人，都可以成为局势失控的导火索。

### 3. 高级钢铁与兵器品质升级
- 主题：地方冶炼能力的差异，使某些区域的刀剑、枪头、甲片品质远高于别处。
- 变化内容：高品质钢材不只是军需资源，也是一种节镇之间的隐性议价筹码。
- 涉及区域：徐州、荆南、江淮、河北、洛阳周边。
- 对政权 / 节镇 / 民间的影响：官营军工作坊与民间铁匠并存，优质钢料会吸引军头垄断、黑市走私与匠户逃亡。
- 可转化方向：一把“徐钢”旧剑、一张甲片裂纹、一名被掳走的铁匠，都能串起势力争夺和身份线。

### 4. 酒榷与赋税的微调
- 主题：战乱年代对酒税、曲坊、坊市征收的反复调整，是财政吃紧时最快碰到民间的一只手。
- 变化内容：中央一旦放松酒榷，地方往往会用别的名目补回来；中央一旦收紧，黑市与私酿又会立刻膨胀。
- 涉及区域：洛阳、开封及北方曲坊密集地。
- 对政权 / 节镇 / 民间的影响：对朝廷是税源，对节镇是补军费的现钱，对百姓和掌柜则是最直接的生计波动。
- 可转化方向：免税符、私曲配方、夜查酒坊、军营断供，都适合直接写成场景。

### 5. 盐铁、商票与信用网络
- 主题：盐铁榷利、跨区域商贸与类似“飞钱”的信用凭证，继续塑造晚唐五代的经济神经。
- 变化内容：大宗货物未必全靠现钱流转，凭证、盐引、账簿和熟客网络本身就是权力。
- 涉及区域：汴梁、江南港口、运河沿线、河北军镇。
- 对政权 / 节镇 / 民间的影响：官府借它筹军需，商人借它周转货物，节镇则可能把它变成自己的财政外壳。
- 可转化方向：盐证、商票、账簿、暗码都能成为可争夺的核心道具，失窃一张，牵连的可能不是一家商号，而是一整条军需线。
