# 风格细则

## 语言底色：冷、硬、稳、痛、留白

- **冷**：叙述者不发热。不替人物感动，不替读者感叹。
- **硬**：句子短，骨头多，脂肪少。能用动词不用形容词。
- **稳**：节奏可控，不因情绪起伏而忽快忽慢。
- **痛**：人物有代价。每次选择都有失去的一面。
- **留白**：不写满。读者需要自己拼的，不给现成答案。

## 风格四层检查清单

### 第一层：武侠味（必须可感）

每个涉及动作/战斗/身法的段落，检查：
- [ ] 是否有至少一处可识别的招式/兵器/内力描写？
- [ ] 读者能否"看见"身体动作（不只是"气息""阴影"）？
- [ ] 战斗是否有节奏变化（快/慢/停）？
- [ ] 结果是否由人物选择和武学逻辑决定，而非作者安排？

### 第二层：权谋动机链（必须成立）

每个涉及人物决策的段落，检查：
- [ ] 角色为什么这么做？（不能是"作者需要"）
- [ ] 他手里有什么信息？（不能多于他已获得的）
- [ ] 他想要什么？（短期目标 + 长期利益）
- [ ] 他付出了什么代价？（每次行动都有代价）

### 第三层：悬疑信息释放（必须清晰）

每个涉及信息揭示的段落，检查：
- [ ] 读者在此时应该知道什么？不应该知道什么？
- [ ] 信息是通过物证/动作/对话释放，还是旁白告知？
- [ ] 是否有硬物证支撑？（物证 > 对话 > 心理）
- [ ] 揭示是否太早（破坏悬念）或太晚（读者困惑）？

### 第四层：冷硬语言压缩

前三层通过后：
- [ ] 是否有冗余形容词/副词可以删除？
- [ ] 是否有"作者替角色说"的句子可以砍掉？
- [ ] 是否有重复信息可以合并？
- [ ] **警告：压缩时不可破坏武侠/权谋/悬疑的可读性**

## 句式规则

- 短句为主，长句辅助。以句号为单位控制节奏。
- 避免"不是……是……"结构密度过高（全章不超过 3-4 处）。
- 避免连续三个以上"的"字句。
- 比喻必须服务信息释放，不写纯装饰性比喻。
