# 七人鬼筹局 · 规则整理版

本文件将 **“七人鬼筹局”** 作为独立外部游戏记录，只保留规则、结算、信息结构和主持暗账。

阅读分层：玩家开局只读“玩家公开规则”；主持者阅读全篇并维护暗账；“隐藏规则”只在触发条件成立时向玩家公布对应部分。

## 一、玩家公开规则

七人入局，其中一人为内鬼。所有人知道有内鬼，但不知道是谁。每人初始 2 枚筹码。筹码黑箱，每人只知道自己的筹码。房外结算检查时筹码为零者，立即处决；入房成本造成的房内暂时零筹，不立刻处决。

游戏最多七轮。七轮结束，或场上只剩三人或更少时，进入终局结算。终局时按筹码排序，筹码最高的三人存活，其余人死。若第三名与第四名筹码相同，则所有与第三名同筹者全部死亡，不进入生还名额；若场上只有三人或更少，没有第四名，则不触发并筹同死。

每轮玩家会被分入房间。真实入房者先支付 1 枚筹码作为入房成本，房内另有 2 枚公共筹码。落筹前有半炷香室内议事；双方可以承诺、试探、撒谎、沉默、诱导，但不得展示筹码或背牌，不得搜检、胁迫、交换实物证明。议事结束后，双方同时选择“平分”或“独占”。

| 双方选择 | 结果 | 净变化 |
| --- | --- | --- |
| 平分 / 平分 | 各得 1 枚公共筹码 | 双方净 0 |
| 独占 / 平分 | 独占者得 2 枚公共筹码 | 独占者净 +1，平分者净 -1 |
| 独占 / 独占 | 公共筹码另行结算 | 双方净 -1 |

房间结果和筹码变化均不公开。房间结束后，存活者回大厅公开议事一炷香。玩家可以质问、试探、撒谎、提议公约、逼人交账、暗示自己见过谁、推动投鬼；不能展示筹码，不能要求主持者公布房间记录，不能证明自己真实入房或待房，不能私下耳语或只对部分玩家传话。

从第二轮开始，公开议事后必须投鬼。投票私下进行，统一开匣。每名玩家必须写下一名当前存活玩家，不得弃票或投空票。7 人需 4 票，6 人需 4 票，5 人需 3 票，4 人需 3 票。内鬼票作废；只有投票成功时，才公布“有一票作废”。投票通过则被投者处决，投票失败则无人处决，也不公布是否有鬼票作废。

每人每轮有一次私下揭发机会。揭发格式为：“我揭发 A 与 B 本轮真实同房，并夺取 A / B 的筹码。”揭发成功，揭发者夺取指定目标全部筹码，目标筹码归零并处决；揭发失败，揭发者处决。第一轮无投鬼，公开议事后直接进入揭发；第二轮起，投鬼结束且游戏仍继续时，才进入揭发。

## 二、主持隐藏规则

### 1. 投死内鬼

投鬼处决若命中内鬼，主持者公开：
> 此人为内鬼。

随后公布隐藏规则：
> 内鬼被投鬼处决后，须指定新内鬼，游戏继续。

旧内鬼秘密指定一名仍存活玩家成为新内鬼，旧内鬼剩余筹码归新内鬼。本轮立刻结束，马上开始新一轮。指定对象不公开；其他玩家只知道内鬼已经换代。
投鬼只能换鬼，不能真正除鬼。

### 2. 真正除鬼

真正除鬼的方法是：当前内鬼因筹码归零而死亡。
真正除鬼一旦成立，游戏立即结束，剩余存活者全部存活。此时不再进行终局排序、并筹判断、投鬼、揭发或揭发结算；已提交但尚未结算的揭发作废。

### 3. 淘汰筹码

若有人被淘汰，除非其他规则明示其筹码归属他人，否则其剩余筹码归当前内鬼。
揭发成功是例外：被指定者的全部筹码归揭发者。
若被投鬼处决者就是内鬼，则旧内鬼秘密指定新内鬼后，其剩余筹码归新内鬼。若内鬼因筹码归零而真正除鬼，则无剩余筹码可归。

### 4. 内鬼限制与特殊房间结算

内鬼不能发动私下揭发。
独占 / 独占时，若内鬼不在本房，公共筹码归当前内鬼，内鬼 +2。若内鬼在本房，公共筹码作废消失，内鬼不额外得筹。

## 三、每轮流程

任意房外结算节点后，都先执行结算检查：
1. 清算所有房外零筹者，令其立即处决；入房成本造成的房内暂时零筹不在此时清算。
2. 若当前内鬼因零筹被处决，触发真正除鬼，游戏立即结束，剩余存活者全部存活。
3. 若未触发真正除鬼，但场上只剩三人或更少，立刻进入终局结算。
4. 若以上均未触发，才继续本轮后续流程。

### 1. 背牌与分房

每轮普通玩家抽玄、白、赤三类背牌；同签者表面上会被分入同房。内鬼持鬼签，可补成任意签面，使所在房间表面上仍是同签入房。
普通玩家只知道自己的背牌，不知道别人背牌。内鬼知道所有人的背牌、所有人的筹码和自己的鬼签。
内鬼每轮必须入房。奇数人数局，内鬼借某名玩家的脸入房，被借脸者待房；偶数人数局，内鬼以自己本面入房。

一张脸一轮只能出现一次。若内鬼借 A 的脸，真 A 必须待房，不能同时真实入房。待房者不支付入房成本，也不获得筹码，可以声称自己没进房，但无法证明。

连续两轮不得重复真实同房关系。也就是说，A 本轮真实同房者不能与上一轮相同。

表面见人关系优先避免连续重复，但不是硬约束。若真实不重复与表面不重复无法同时满足，以真实不重复为准。

### 2. 第一轮

1. 发背牌。
2. 内鬼分房；奇数局启动假扮 / 待房。
3. 真实入房者支付入房成本；房内暂时零筹不处决。
4. 室内议事。
5. 同时选择平分 / 独占。
6. 房间结算；出房后执行结算检查。
7. 存活者回大厅公开议事。
8. 私下揭发；每条揭发结算后执行结算检查。
9. 轮末整理暗账，进入第二轮。

### 3. 第二轮及以后

1. 发背牌。
2. 内鬼分房；按当前人数奇偶决定假扮或本面入房。
3. 真实入房者支付入房成本；房内暂时零筹不处决。
4. 室内议事。
5. 同时选择平分 / 独占。
6. 房间结算；出房后执行结算检查。
7. 存活者回大厅公开议事。
8. 先投鬼。
9. 若投鬼触发隐藏规则，按隐藏规则处理。
10. 若游戏仍继续，进入私下揭发；每条揭发结算后执行结算检查。
11. 轮末整理暗账，进入下一轮。

### 4. 揭发结算细则

揭发只能针对本轮真实同房关系，不能追溯历史轮次。A、B 必须是当前仍存活玩家，且均不得为揭发者本人。揭发者必须在提交时指定夺取 A 或 B 的筹码。

多人同轮揭发时，揭发同时入匣，由主持者按进入揭发阶段时的筹码从高到低结算；同筹则按开局固定座次结算。

每一条揭发结算后，立即执行结算检查。若触发真正除鬼或终局结算，后续未结算揭发全部作废。若某人结算前已被处决，其未结算揭发作废；若指定目标在结算前已被处决，该揭发作废，不能临时更改目标。

## 四、主持暗账

试玩或正式主持时，必须维护这些表：
1. **真实身份表**：玩家，当前是否内鬼，是否已死。
2. **每轮背牌表**：轮次，玩家，背牌 / 鬼签，鬼签补成哪一对表面背牌。
3. **真实分房表**：轮次，房间，真实入房者。
4. **房内议事表**：轮次，房间，双方关键发言，策略判断，最终选择理由。
5. **表面见人表**：轮次，玩家，房内看到的脸。
6. **借脸表**：轮次，内鬼借谁的脸，被借脸者是否待房。
7. **筹码表**：轮次，玩家，轮前筹码，入房成本，房内收益，揭发变化，投鬼变化，淘汰归属，轮后筹码。
8. **投票表**：轮次，玩家，投票对象，是否有效。
9. **公开口供表**：轮次，玩家，公开声称内容，是否真实，谁能验证。
10. **终局结算表**：玩家，终局筹码，是否处于第三 / 第四名并筹边界，是否进入生还名额。

## 五、推理与策略附录

房内见人不等于验人：玩家看到的是一张脸，不一定是本人。

奇数人数局中，内鬼必须借脸入房，不能用本面。因此，奇数局房内见到某张脸，可以弱排这张脸是本轮内鬼本面。

偶数人数局中，内鬼以本面入房。此时房内见到某人，不能弱排此人。

死亡、换鬼、人数奇偶变化都会削弱旧见人账。新内鬼不需要额外保护轮，因为所有存活者理论上都有可能被指定为新内鬼。

如果六名非内鬼玩家存活足够久，并交换多轮见人账，可能通过集合排除法强排初始内鬼本面。所以内鬼必须尽早制造人数变更，让旧账因死亡、换鬼、偶数局本面入房而贬值。

## 六、展示节奏附录

若将本局用于叙事展示，不宜一次性向读者灌输全部规则。规则应随局势逐层显影，让读者先理解当下生死压力，再逐步意识到信息结构更深。

推荐释放顺序：

| 阶段 | 读者需要知道 | 场面功能 |
| --- | --- | --- |
| 入局 | 筹码、归零、平分 / 独占、前三生还 | 建立囚徒困境和生死压力 |
| 第一轮 | 筹码黑箱、公开议事、一筹自报、公约 | 建立合作假象与信用账 |
| 对账阶段 | 房内见人账可用于排鬼，但公开见人有揭发风险 | 让读者意识到信息也是筹码 |
| 借脸暴露 | 房内见到的是脸，不一定是本人 | 打破“见人即验人”的误解 |
| 投死内鬼 | 投鬼只会换鬼，新内鬼不公开 | 撤回第一次胜利，抬高绝望感 |
| 后段乱局 | 一筹、谎报、待房、亏筹方式互相冲突 | 逼玩家用口供寻找真实同房关系 |
| 终局揭发 | 真正胜负点是让当前内鬼筹码归零 | 完成从“找鬼”到“除鬼”的理解升级 |

叙事原则：
1. 公开规则只讲玩家当下必须知道的部分。
2. 隐藏规则只在触发时公布，不提前解释。
3. 主持暗账不直接呈现给读者，只通过口供冲突、处决结果和角色反应外化。
4. 读者应跟随破局者逐步更新理解，而不是先读完说明书再看人物执行。

## 七、硬约束速查

| 硬约束 | 说明 |
| --- | --- |
| 一张脸一轮只能出现一次 | 若内鬼借 A 的脸，真 A 必须待房 |
| 内鬼每轮必须入房 | 奇数借脸，偶数本面 |
| 真实同房不得连续重复 | 表面见人优先避免重复，但以真实不重复为准 |
| 内鬼不能揭发 | 否则无风险收割 |
| 投死内鬼只会换鬼 | 新内鬼秘密指定，本轮立刻结束 |
| 真正除鬼只有内鬼零筹 | 成立后游戏结束，剩余存活者全部存活 |
| 入房暂时零筹不处决 | 只在房外结算检查时清算零筹 |
| 第二轮起先投鬼后揭发 | 投鬼后若游戏仍继续，才进入揭发 |
| 揭发只查本轮真实同房 | 不查历史，不可包含自己 |
| 内鬼本房双独占不得额外得筹 | 公共筹码作废消失 |
| 淘汰筹码默认归内鬼 | 揭发成功等明示例外除外 |
| 三人或更少立刻终局 | 任意结算节点后触发 |
| 并筹同死只看第三 / 第四名边界 | 存在第四名且与第三名同筹时触发 |
