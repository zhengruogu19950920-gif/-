# 章间武学小札：规范与示例

按作者本轮要求，在章节之间增加对上一章所出现武学、心法的简短注释。尚未披露的内容默认省去；仅在正文确有缺损或未能辨识的记录需要照录时，按材料本身保留相应标记。栏目暂名“武学小札”，按作者讨论结论逐行采用“文字：文字”，帮助读者理解已经看见的动作、能力及条件，并保留未公开的部分。当前以第十节04版简短字段为准；03及更早样例按版本保留。

## 一、位置与使用时机

- 阅读顺序为：上一章正文 → 该章必要的考据／名词注释 → 武学小札 → 下一章正文。小札与考据注释各自成段；已经有独立章间排版时，小札可单列一页。
- 选上一章新出现、发挥关键作用或增加了新认识的武学、心法、招式及有名兵器，逐项核对覆盖，不能只选主角心法而遗漏理解交战所需的其他概念。通常一至两项；首次集中登场时，可按本章实际需要多列短札，不以推荐数量压掉必要项。
- 每项逐行写“字段：内容”，一行一个字段，内容以短句为主；不以80–150字凑篇幅，也不将字段内容重新拼成长段。同属一部的多人可合为一组，每人以相同字段分别列出。武学／招式用“武学小札”，兵器用“兵器小札”，均在正文结束后统一分隔。
- 上一章没有相关新信息，可以省略。以后再次出现同一武学，优先补本次新增的事实，不反复抄整张卡。
- 正文仍须交代理解人物行动所需的武学信息。小札整理已有披露，不承担补齐战斗因果的职责；读者跳过小札也能继续阅读。

## 二、披露边界

**截至上一章结束，读者已从当前版本正文获得的信息，是小札的披露上限。**作者设定集用于核对一致性，不直接作为读者版内容来源。

1. 记录已展示的作用、名称、修习者、来源、限制。场景只展示了一次应用，就只写“本章所见”，不把它推成普遍定律。
2. 人物的猜测、转述或可能误认，必要时注明说话者，不由小札认证为真相；正文只给了局部资料，就只录这些资料，不增未知字段。读者与人物的认识范围分别判断。
3. 框架、未来章节计划、旧稿已揭示而重构稿尚未写到的内容，不计为当前读者已知。尚未完成正文的回收、突破与伤亡，也不因写进小札而成为已发生。
4. 未公开的传承、人物身份、作用上限与反制方法留在作者资料，不在读者札中列成“未明／不详／未载／？？？”。小札不解释暗线、幕后指令或将来战果。
5. 若确需照录正文已展示的缺字或残缺，使用统一标记，不按隐藏名称字数排列；不列未公开境界总数、分支数量或未来招式占位。隐秘关系不通过字段名暗示。
6. 作者仍在设计的内容，在作者工作记录中标“未定”。读者札只录当前正文已有资料，不把尚未设计的内容包装成秘密或待揭问题。

## 三、未知信息的处理

尚未交代的资料默认省去。“未明”换成“不详”“未载”“暂缺”仍会提示读者后面有一个答案，不能只换词而保留未知清单。完整门径、其他能力、铸材来源、施伤者与解法等，若本章没有披露，就不另列。

例外只用于正文已展示的材料状态：残谱确有缺字、残页，或角色当场明确无法辨识。此时可忠实记“缺字”“残页”或该人的判断；不借注释暗示缺处必有特殊能力与后续揭晓。

作者工作记录仍可用“未定”“不详”维护资料与伏笔，读者版不照搬这份待办清单。

## 四、推荐字段与版式

当前读者版采用逐行字段式，各行呈现“文字：文字”。以下字段按条目需要选择；无需每项填满，也不作战力面板。已出现的名称、作用、形制与可靠依据优先；只列有资料的字段。

| 可选字段 | 内容 |
| --- | --- |
| 名称 | 已在正文出现的名称；未具名时沿用正文已有称呼，不直接套作者设定名 |
| 归属／类别 | 按正文已披露的层级注明，如“天雄寺·天龙八部·天部”“天雄寺·天龙八部·夜叉部”、家传武学或家传兵器；武学来源与效命对象分开，不将所有武学归入八部 |
| 门路／武技 | 无名业风为本章三夜叉所修的夜叉部门路；风无相、地无常、水无形为各自代表武技，字段分列，不能混作总纲 |
| 所见修习者 | 当前正文明确展示或可靠说明的人物；只出手但尚未披露姓名时保留原称呼 |
| 作用／形制 | 用短句记录已经表现的作用或可见形制，不复述本章战果 |
| 已知传承 | 正文已经明确的授受关系；没有资料便省去 |

书面语气以作用、条件和可见代价为中心。需要解释的佛学、经脉或兵器词义可以简注；战力排名、数值面板和将来能击败谁，不属于本栏目。

以下为字段式简模板，当前完整读者例以第十节试稿04为准：

```markdown
---

**【武学小札·已公开名称】**

归属：……。  
传承：……。  
已出现的法门：……。

<!-- 字段按已有资料选择，无资料的字段直接省去。 -->
```

## 五、天众敬示例：仅截至第一章开头试写

以下示例只依据当前对话中“旧炭窑转移、择路、第一记格挡”的试写段落，不把九月框架中的后续交战视作已披露。它用于验证格式，尚不是完整第一章的正式附注。完整章节写成后，应按最终正文重新编写。

### 读者版示例

> **【武学小札·天众敬】**
>
> **所见修习者**：高崇岳。
>
> **本章所见**：能察知遮挡处的人体气血，辨出人与马所在的不同位置；交手时，凭对方气血变化移剑接招。
>
> **所见限制**：高赶路后最初只辨出马声，停步缓息后才察知人所在。完整施展条件不详。
>
> **源流与全貌**：高曾在天雄寺修习。余？？？

### 作者核对依据（不放入读者版）

| 小札内容 | 试稿已有证据 | 保留边界 |
| --- | --- | --- |
| 名称与所见修习者 | 高崇岳为视角人物；正文明确写“天雄寺里学过的天众敬” | 尚未说明的其他修习者不列入 |
| 遮挡处的人体气血与位置 | “有一线细微的气血起伏，停在高处，久久不向前移”；随后判断马未走、人已在高处 | 不由此推出距离无限、无须条件或能看透一切 |
| 发力变化与接招 | “方才还能辨出的气血忽然急促起来”；高移剑，短刺撞上剑脊 | 不将这一幕改写成读取对手思想或确认未来进阶 |
| 当时的辨察困难 | 高最初等马头出现，随后停步、缓息、分辨出高处的人 | 只记录当时过程，不写“必须绝对安静才能使用” |
| 完整传承与境界 | 作者有完整武学卡，当前段落未公开完整来源与境界名 | 读者版暂遮；不借框架提前公开，也不列问号境界清单 |

后续若正文确实点出某一法门名称并展示其作用，再补名称及已见作用；仍未展示的内容继续遮盖。未来章节对条件有新证据，可写一则补记，并校正此前仅凭局部场景形成的认识。

## 六、章后写入核对

每写一项，作者工作稿记录对应正文段落或原句，再核对武学设定；这份依据不随读者小札刊出。最终检查名称、人物、作用、限制及隐藏字段是否均符合当前章节的信息边界。

小札不能把伏笔从“未回收”改成“已回收”，不能改变章节定稿状态。首次小札与后续补记在各章维护；本文件只维护栏目规范和示例，避免建立第二套正文进度。

>
