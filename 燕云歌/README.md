## 在 Obsidian 中使用

下载或克隆仓库后，在 Obsidian 中选择“打开文件夹作为库”，选择本 `燕云歌` 目录。相对 Markdown 链接可在 GitHub 和 Obsidian 中使用；图片保存在资料目录的 `06-附件与归档/图片` 中。

`.obsidian` 保存原库配置、已上传的其他插件与主题。Remotely Save 程序和账号设置通过本地 Obsidian 管理。
