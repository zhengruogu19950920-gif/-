## 文化名家事迹

### ✨ 郭忠恕（约929-977）
- 人物：<span style="font-family:'KaiTi','SimHei'; font-size:1.05em;">河洛出身的书画、金石与文字学怪才，五代末至宋初的“异人”形象，擅长后世称为“汉简”的古文字研究，笔墨如刀而意趣又似江湖。</span>
- 生平事迹：<span style="font-family:'仿宋'; font-size:0.95em;">早年在往洛阳仕宦的过程中，948年出仕武宁节度使刘熙裔（刘贺以后），十九岁时受令在许州担任推官。950年郭崇韦叛乱后，他随刘允出奔，冒死在宋州怒斥奉诏之臣冯道，并在刘允未能成帝后逃遁山野；之后在郭威成为帝时重新入仕，曾同时掌管宗室司与太学卦书科。宋朝建立后他在朝中斗嘴频繁被贬，醉酒殴官、卖饰、连体面行走，976年赵光义亲迎他复任，977年再犯礼法被发配后在途中病逝。他的《汉简》收录秦石鼓与宣纸，成为文献与秘谱的珍贵线索。</span>
- 同时代可勾连的政治人物：<span style="font-family:'YouYuan'; font-size:1em;">刘允/郭威——他曾试图护送刘允投靠河东，却在郭威迅速称帝后逃入深山，之后在郭威、赵光义之间游走，既是反骨才子也是朝廷不能放弃的奇葩。</span>
- 可架空的武侠背景：🌀 <span style="font-family:'KaiTi';">汉简里的龟甲字与石鼓刻画暗藏阵法元气，登山采水时向山野道士讨酒，竟意外破解前朝遗留的“行殇阵”符号；醉时破门喝令的勇气被江湖人士视为血性，传来“墨麟”之名。</span>
- 可服务的门派 / 秘卷 / 兵器 / 师承线：🔰 <span style="font-family:'FangSong';">以“汗简阁”为核心，秘卷《墨麟行阵》记载以毛笔为剑、以籀书结阵的“驱魂笔”技法，附带“雪霁江行图”下的流云团双刃（可依附在画轴、诗笺）；师承可设为隐居魏阙的古文书生，门派以章法为心法，配套以龙井水调的解毒丹。</span>
- 与前传 / 正传的适配建议：💡 <span style="font-family:'SimHei';">可在赵则平尚未确认身份前安排一次赴京，在郭忠恕被发配途中救助他，借由其对“汉简”刻字的蛛丝马迹揭示前传正传中的某位朝臣身世暗号，亦可让赵则平在郭忠恕落魄时获得一页秘笺，为后续正传中“书声笔影”的线索做铺垫。</span>

### ⚜️ 张昭（894-972）
- 人物：<span style="font-family:'KaiTi','FangSong'; font-size:1.05em;">自称张孺子后裔、杰出的史官与文人，从王审知门下受业，通读十三史，后又参与《旧唐书》与多部实录的撰修，是贯穿五代政权更迭的见证者。</span>
- 生平事迹：<span style="font-family:'YouYuan'; font-size:0.95em;">在平卢莅地的王审知为其父张直提供孔孟教育，早年随父在平凉、赵州奔走、参予田猎间行文笔记。922年李存勖夺赵地后，张昭带卷入军营，由张宪举荐得推官与监察御史职，随后随张宪入晋阳。926年李存勖暴死、李嗣源拥立之际，他力主察封、主张逮捕李存沼，并替馀党书写安民通告，因而与李嗣源、宗室之间交错复杂。在后续后唐-后晋-后汉-后周-宋的轮换里，他以史说政，参与定本，使皇朝更替与官吏心态成为笔下的刀。</span>
- 同时代可勾连的政治人物：📜 <span style="font-family:'SimHei';">李嗣源/李存勖——他在太原劝张宪擒拿李存沼，已将自己与李嗣源的登基紧密联系，而此前又与李存勖麾下的文臣交游，可做镜面对照。</span>
- 可架空的武侠背景：🌊 <span style="font-family:'KaiTi';">以“十三史”拆解朝代兴衰符的“兴亡诀”，擅以阵道看人心，能凭一句诗推断晋阳义军调遣，历代档案成了他的“流年铁索”；江湖传他持“史笔”在水榭之中写出“河岳风雷”遗文，待用来化解城门之险。</span>
- 可服务的门派 / 秘卷 / 兵器 / 师承线：🕯️ <span style="font-family:'FangSong';">寄身“纪文馆”，馆中秘卷《乾坤朔月录》以史笔攻势书出八方劲气，配套兵器为“纪文笔戟”（兼具修书与破阵功能），师承则落在山西一支“书衡派”，以“崩流”步法配合“史笔投影”。</span>
- 与前传 / 正传的适配建议：🧭 <span style="font-family:'SimHei';">可让赵则平在为北伐募兵或查访旧籍时拜访张昭，将其对李嗣源/李存勖起落的视角作为“国运感知”的教材，亦可借张昭手中所藏的“河岳风雷”残卷开启正传中关于“枯木明燧”门派传承的起点。</span>

### 🎋 李舜弦（约900-926）
- 人物：<span style="font-family:'KaiTi'; font-size:1.05em;">来自梓州的波斯移民女诗人，入蜀后成为后主王衍的昭仪，能以汉语书写宫体词，作品收入《十万绝句》，并与兄长李殉、李敖组成药理与诗词的兄妹档。</span>
- 生平事迹：<span style="font-family:'YouYuan'; font-size:0.95em;">家族在黄巢乱后避居蜀中，随后进入蜀宫，兄长在宫中以药膳与诗词著称，她在宣华苑中作《月华如水》等词。后主王衍继位（919-924），她随着后主宴徂翠微，与侍臣共饮，因美貌与才情受宠。925年后唐李存勖攻蜀，926年王衍与后妃、李舜弦等人被赵匡胤所杀，李舜弦随宫女被辽西所屠。</span>
- 同时代可勾连的政治人物：👑 <span style="font-family:'SimHei';">王衍/李存勖/李嗣源/后唐庄宗——她的命运绑在王衍的纵逸之上，灭亡之时又被李嗣源旗下将领与庄宗军队并肩展开攻势。</span>
- 可架空的武侠背景：🎶 <span style="font-family:'KaiTi';">可将其诗词化为“琼瑶诀”，每句词皆为暗藏回旋的药物与阵道，她与兄长研制的“月华粉”可治伤亦可迷魂；她与宫中乐师结成的“外庭羽乐”能用音律召唤遥远波斯神祇，引得不知名江湖势力窥视。</span>
- 可服务的门派 / 秘卷 / 兵器 / 师承线：🌸 <span style="font-family:'FangSong';">设想“月华馆”以词为剑，秘卷《瓊瑶集》记载“寒香调”“月华如水”两曲，可配合轻纱“琼雾剑”与“丝旒羽”，师承为她父辈流浪波斯医书承传下的“玉漏·香径”套路。</span>
- 与前传 / 正传的适配建议：🕊️ <span style="font-family:'SimHei';">赵则平可在蜀川征调中遇见她残留的曲谱或香料，与其兄李殉的药方并行，实现前传中“香药双绝”的支线；她的惨死可成为赵则平后续投向“以词救危”门派的大义原点，并扣紧正传对“洛阳宫妓、外邦织女”线索的继续。</span>
