# 卢龙与幽州：地名及第二章行程核对

依作者“关于卢龙的地名请特别关注”的要求，为[新第二章框架V1](<../02-赵则平前传/02-重构/04-第二章/第二章_空谷足音_重构框架V1_2026-10-15.md>)单列地理依据。这里区分史籍可支持的判断、小说场景与尚未核定的精确位置，不将旧素材库视为已经考定的地图。

## 一、目前可用于起草的区别

| 称呼 | 本章使用范围 | 需要避免的混同 |
| --- | --- | --- |
| 卢龙军镇、卢龙节度使、卢龙军、卢龙幕府 | 赵德钧所领军镇及其军政机构，治所在幽州 | 不把“卢龙”一律当作一座与幽州相邻的城；不能把回幕府写成返卢龙县 |
| 幽州、幽州城 | 本章返回的军镇治所；现代定位只作今北京一带 | 不以明清北京城门、城垣及今日市区中心直接复原五代幽州城 |
| 平州、卢龙县 | 与幽州分属不同地点；《新唐书》平州条明确记载徙治卢龙 | 不把同名县城作为赵氏在幽州的治所，也不为返城绕去平州 |
| 军都陉 | 幽州西北、昌平及居庸一线的交通山道 | 山道不等于某一座现存关城；不把一条陉道压成断碑旁的单一谷口 |
| 居庸故关、军都关、纳款关等史籍称法 | 用来核查历史关隘的关联与沿革 | 不直接断言不同年代的名称、位置与建筑全部重合；本章具体采用何称须随年份复核 |
| 古北口 | 与军都陉、居庸一线分开辨认的通路 | 旧安序卡的“古北口送信”不能自动成为第一章同一地点的旧事 |

尤其注意：唐代地志在平州条还记有一支“卢龙军”，而赵氏语境的“卢龙军镇”是另一层级及时代的军政称呼。看到同名不能跨条目、跨年代合并。各时期军镇辖州也会变动，本章暂不列一张未经断代的完整辖区表。

## 二、本章的行程责任

采用相对路线：**军都陉关外战地 → 山路担架撤收 → 关内医者／车辆安置处 → 分程返幽州城 → 幕府安排的客舍。**总体是由幽州西北的山地撤向幽州，沿途道路可以曲折，不把每一折都写成朝正南。

关内安置处是小说设置，须选在担架可达、车辆可接的位置。车若不能进入某段陉道，先抬到可通车处，不能让大车突然出现在窄谷或陡坡。第一章只写抬往关口，第二章开段必须保留这段运输的身体代价。

三种速度分别核算：前队精骑、单骑递报、载伤者的车辆。伤车又受病情、路面、换乘和停歇影响，不能把“快马可到”写成“重伤者当晚必到”。现阶段安排关内留观一夜、获准后转运，不把这一建议当成已经证明足以返城的具体日程。

正式起草前需定一张小表：关口所指位置、关内急救地点、车可通的起点、返城路段与预计停歇。古县治未定位、关口未选定之前，不给出精确古里或公里数。确认路径后再核用时；若与伤情不合，调整转运及会客时点。

幽州发往洛阳的结果续报另有递送时间。本章可写奏报发出及接到人的本地记录，不让朝廷当日获知、批复、使者又当日返回。

## 三、已读史料及其适用范围

1. [《新唐书》卷三十九·地理志，Kanripo文本](https://github.com/kanripo/KR2a0027/blob/320ec8ace39863ceb2c778178c6074a2348d2973/KR2a0027_039.txt)：幽州条、昌平条、平州条分别核读。昌平条载“北十五里有軍都陘”，接着载“西北三十五里有納款闗即居庸故闗亦謂之軍都闗”；平州条载“初治臨渝武德元年徙治盧龍”。这些记录支持分开山道、关隘、幽州及平州卢龙，不能据其古里数直接计算今地之间的距离。
2. [《资治通鉴释文》卷二十八，Kanripo文本](https://github.com/kanripo/KR2b0016/blob/711f8e764c0896c704fa63c6fadbbde1a27e92be/KR2b0016_028.txt)：在“卢龙”下注“唐之藩鎮也”，并记“治幽州”。此处用来确认军镇与治所的层级；所列辖州不能未经断代直接用作小说全部时段的行政表。
3. [《钦定日下旧闻考》卷一百五十四，Kanripo文本](https://github.com/kanripo/KR2k0036/blob/9e9d00e40282c64d0a56501bff41038877c8eccf/KR2k0036_154.txt)：汇录居庸、军都陉及历代关名材料，也同时收入明代建城记录。可作查找旧史出处与沿革的线索，不能把汇编里的明代城墙、驿站直接放进五代。
4. [同书卷一百五十二](https://github.com/kanripo/KR2k0036/blob/9e9d00e40282c64d0a56501bff41038877c8eccf/KR2k0036_152.txt)：并列古北口、居庸关等关隘，并录密云与古北口的关系。这里只用于辨别两条通路，明清军事营制及当时称法不倒灌为五代现场。

所引为古籍数字文本，尚未据历史地图和考古材料完成县治、关城与道路的坐标复原。当前能确认的是称呼层级与路线不能混同，不能据此声称第二章精确行程已经核定。
