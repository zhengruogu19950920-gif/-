# 章间武学小札：规范与示例

按作者本轮要求，在章节之间增加对上一章所出现武学、心法的简短注释。未披露内容可用“？？？”或“不详”遮盖。栏目暂名“武学小札”，采用简短谱录的语气，帮助读者理解已经看见的动作、能力及条件，并保留未公开的部分。名称、篇幅与排版为试行建议。

## 一、位置与使用时机

- 阅读顺序为：上一章正文 → 该章必要的考据／名词注释 → 武学小札 → 下一章正文。小札与考据注释各自成段；已经有独立章间排版时，小札可单列一页。
- 选上一章新出现、发挥关键作用或增加了新认识的武学、心法；必要时附与其直接相关的招式或兵器。推荐每次一至两项，每项约80–150字，用短段谱录；只有确有必要时才略加长。
- 上一章没有相关新信息，可以省略。以后再次出现同一武学，优先补本次新增的事实，不反复抄整张卡。
- 正文仍须交代理解人物行动所需的武学信息。小札整理已有披露，不承担补齐战斗因果的职责；读者跳过小札也能继续阅读。

## 二、披露边界

**截至上一章结束，读者已从当前版本正文获得的信息，是小札的披露上限。**作者设定集用于核对一致性，不直接作为读者版内容来源。

1. 记录已展示的作用、名称、修习者、来源、限制。场景只展示了一次应用，就只写“本章所见”，不把它推成普遍定律。
2. 人物的猜测、转述或可能误认，应写明“据某人所言”“所用功法不详”等依据，不由小札认证为真相。读者已获知、人物尚不知的内容可以整理；人物不知与读者不知分别判断。
3. 框架、未来章节计划、旧稿已揭示而重构稿尚未写到的内容，不计为当前读者已知。尚未完成正文的回收、突破与伤亡，也不因写进小札而成为已发生。
4. 保留未公开的传承、人物身份、作用上限与反制方法；不借注释解释暗线、幕后指令或将来的战果。
5. 遮盖方式也要检查：统一用三个全角问号“？？？”，不按真实名称字数排列；不列出未公开的境界总数、分支数量或未来招式占位。姓名、称号之间的隐秘关系也不通过字段名暗示。
6. 作者仍在设计的内容，在作者工作记录中标“未定”。读者版只保留能由当前故事提出的问题，不把尚未设计的内容包装成已经存在的秘密。

## 三、“？？？”与“不详”的分工

| 标记 | 使用条件 | 写法原则 |
| --- | --- | --- |
| ？？？ | 已有设定或故事线索，但具体内容尚未向读者披露 | 放在通用字段如“源流与全貌”；不展示真实字数、具体阶数或未公开专名 |
| 不详 | 截至此章，现有叙述不足以确认的资料或结论 | 表示当前材料的认识边界，不宣称世间无人知晓，也不宣称该能力不存在 |

例如，正文尚未说出的境界名称可以遮盖；没有说明创立年代，或一场交手不足以确认完整施展条件，可以写“不详”。已公开的内容正常填写，不为制造悬念重新遮掉。

## 四、推荐字段与版式

当前读者版采用短段谱录，减少固定字段。以下字段供作者核对内容；刊出时按阅读需要合为一段，“本章所见”优先。

| 可选字段 | 内容 |
| --- | --- |
| 名称 | 已在正文出现的名称；未具名时沿用正文已有称呼，不直接套作者设定名 |
| 所见修习者 | 当前正文明确展示或可靠说明的人物；只出手但尚未披露姓名时保留原称呼 |
| 本章所见 | 已显露的作用及关键动作，用短句说明 |
| 所见限制 | 本章实际遇到的困难；不将人物当时的伤势、心绪等直接写成全门派必然弱点 |
| 源流与全貌 | 已披露内容照写，余下按“？？？”或“不详”处理；未来数量不占位 |

书面语气以作用、条件和可见代价为中心。需要解释的佛学、经脉或兵器词义可以简注；战力排名、数值面板和将来能击败谁，不属于本栏目。

初版字段模板保留作作者工作表，当前读者版以第七节短札为准：

```markdown
---

**【武学小札·已公开名称】**

**所见修习者**：……

**本章所见**：……

**所见限制**：……

**源流与全貌**：……／？？？／不详。
```

## 五、天众敬示例：仅截至第一章开头试写

以下示例只依据当前对话中“旧炭窑转移、择路、第一记格挡”的试写段落，不把九月框架中的后续交战视作已披露。它用于验证格式，尚不是完整第一章的正式附注。完整章节写成后，应按最终正文重新编写。

### 读者版示例

> **【武学小札·天众敬】**
>
> **所见修习者**：高崇岳。
>
> **本章所见**：能察知遮挡处的人体气血，辨出人与马所在的不同位置；交手时，凭对方气血变化移剑接招。
>
> **所见限制**：高赶路后最初只辨出马声，停步缓息后才察知人所在。完整施展条件不详。
>
> **源流与全貌**：高曾在天雄寺修习。余？？？

### 作者核对依据（不放入读者版）

| 小札内容 | 试稿已有证据 | 保留边界 |
| --- | --- | --- |
| 名称与所见修习者 | 高崇岳为视角人物；正文明确写“天雄寺里学过的天众敬” | 尚未说明的其他修习者不列入 |
| 遮挡处的人体气血与位置 | “有一线细微的气血起伏，停在高处，久久不向前移”；随后判断马未走、人已在高处 | 不由此推出距离无限、无须条件或能看透一切 |
| 发力变化与接招 | “方才还能辨出的气血忽然急促起来”；高移剑，短刺撞上剑脊 | 不将这一幕改写成读取对手思想或确认未来进阶 |
| 当时的辨察困难 | 高最初等马头出现，随后停步、缓息、分辨出高处的人 | 只记录当时过程，不写“必须绝对安静才能使用” |
| 完整传承与境界 | 作者有完整武学卡，当前段落未公开完整来源与境界名 | 读者版暂遮；不借框架提前公开，也不列问号境界清单 |

后续若正文确实点出某一法门名称并展示其作用，再补名称及已见作用；仍未展示的内容继续遮盖。未来章节对条件有新证据，可写一则补记，并校正此前仅凭局部场景形成的认识。

## 六、章后写入核对

每写一项，作者工作稿记录对应正文段落或原句，再核对武学设定；这份依据不随读者小札刊出。最终检查名称、人物、作用、限制及隐藏字段是否均符合当前章节的信息边界。

小札不能把伏笔从“未回收”改成“已回收”，不能改变章节定稿状态。首次小札与后续补记在各章维护；本文件只维护栏目规范和示例，避免建立第二套正文进度。
