# AI对话记录管理最高指令 (AI Protocol)

🚨 **ATTENTION ALL AI ASSISTANTS / CLINE SESSIONS** 🚨
**这是专门为所有AI对话窗口设定的最高级别强制规则，在你被要求在此文件夹写入、保存或整理聊天记录时，必须严格遵守以下指令：**

### 1. 绝对禁止文件覆盖 (NO OVERWRITING)
当前文件夹下的任何 `.md` 文件（特别是以日期命名的记录，如 `2026-03-22.md`），可能属于其他独立并行对话窗口（Sessions）的历史存档。**你绝对不可以直接覆盖或重写任何已经存在的文件内容！**

### 2. 每个对话窗口必须使用独立文件 (ONE SESSION = ONE FILE)
当用户要求你“整理对话记录到此文件夹”时，你必须：
- 首先检查文件夹内已有文件，特别是当天的日期前缀。
- **强制使用组合命名法创建新文件：** `YYYY-MM-DD_[当前对话核心主题或编号].md`。
- 例如：如果你是关于“代码审核”的窗口，文件名应为 `2026-03-22_代码审核.md`；如果没有明确主题，请至少使用随机序号或时间戳，如 `2026-03-22_Session_1.md`、`2026-03-22_Session_A.md`。

### 3. 如何追加内容 (APPENDING ONLY IF SAME TOPIC)
- 如果用户明确指令你向某个*特定的文件*追加内容，你必须首先**读取 (read_file)** 该文件的现有内容，并将新内容**追加 (append / write_to_file with full content)** 在文件末尾，绝不允许清空原有内容或只写新内容导致覆盖。
- 如果不确定，请始终**新建独立文件**！

**总结：一窗一档，绝不共用，避免灾难性覆盖！**
