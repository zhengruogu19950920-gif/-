# 《寒枰》序章改稿提纲 V2

## 一、改稿目标与本版取舍

序章让初读者认识一个体弱、聪敏、不愿轻易舍弃的少年，认识他真正信任的父兄，并看到一次求援怎样打断赵家的日常。营救在本章尚未完成，后果不提前揭示。

按最新意见，保留两次回溯：入太行后，与李微对弈时识出茶棚棋局的变种，重新判断原局；最终上嵩山，再在史继演榻边见到当年的棋局，回看已经由自己作出的现实选择。两次回收分别承担局面认识与选择之后的责任，不重复讲解弃子道理。

入场理由采用父召练弓马。兄弟差别落实为病弱少年的体力限制与成年兄长娴熟的弓马；保留亲情和互相信任，不提前把兄长写成处处算计的对手。

正文首次出现时直接交代“渤海—东丹”“耶律倍—人皇王”的对应。注释补充年代和改编边界，基本理解不依赖翻注。

## 二、序章四场

### 第一场：茶棚，一盘尚未下完的棋

**地点与人物：**幽州城外茶棚；赵延祚、两名伪装的老兵、掌柜、来催的仆役。季节暂承接初春，绝对年份另随全书年表统一。

**入场：**先给环境与少年可见的形象：提鱼、湿鞋、清瘦苍白的脸，衣着洁净而不张扬。先让陌生读者看见这个人，再揭示世子身份。

**棋局动作：**

1. 执白的老李头准备放弃角上一小块棋，转而抢外围的要点。他指过那个位置，拈子未落。位置必须可在后续复盘辨认，可借旧棋盘的木疤轻轻标记。
2. 少年看见角上仍有救法，插话并接手。他先计算从边上接出的办法，发现受阻，再选择就地做活；错在低估外围补救成本，不把简单做眼写成老人没发现的旷世妙手。
3. 少年为救角连续应手，执黑者占住老人刚才指过的要点。角上白棋确实活了，外围却开始需要补救。正文呈现动作，不宣布全局结论。
4. 仆役奉父命来催练弓马，棋局被打断，整盘没有结束。少年主要记住救活局部的成果，带着一点得意离开。

**身份反应：**初见时二老打量其衣着，以小郎君相称；仆役称世子后，二老停话、起身、改口，保持普通老兵的表层反应。执白者说话、执黑者划圆的对应保留，不在正文揭露二人身份及配合方式。

**茶钱处理：**若保留赌约，以“角上这块能否救活”为约，不能按未完成的整盘胜负结账。

**本场改变：**他验证了自己有能力找到别人未采用的救法；一处暂未理解的全局代价留在棋盘上。父亲的召唤把他从自己熟悉的棋桌带回家族生活。

### 第二场：校场，父兄与弓马

**地点与人物：**幽州营中校场；赵德钧、赵延寿、赵延祚、少量亲兵。

**身份介绍：**归城过渡中交代少年姓名、赵德钧的身份、亲侄过继关系，以及兄长是外姓养子而弟弟承继家门的位置。分开落笔，不让一个段落同时承担全部身世。

**兄长出场：**有明确体貌、甲胄和动作。通过一段短而完整的骑射或控马动作表现熟练，不再堆叠长枪试重、比武、众人赞叹等多轮展示。部属处理军务时自然找他，显示其实际地位。

**弓马对照：**

- 赵延寿能稳定控马、开弓、放箭，动作已成习惯。
- 赵延祚使用适合自己的轻弓，姿势可以学得认真，臂力和耐力却跟不上；一两次用力之后，手臂发颤、气息难平。选少量准确反应，不用摔倒吐血制造差别。
- 兄长在弟弟放下弓后帮他调整手位，或替他换合适的弓。关切是真实的，不借教学羞辱他。
- 父亲对迟来和敷衍有要求，也清楚其身体承受能力。不给兄弟公开排座次，不将体弱写成无用。
- 少年羡慕兄长的本领，也不愿轻易说练不下去；不在此作“将来靠谋略胜过武力”的宣言。

**突发事件：**练习刚开始或父亲才看过一箭，军士报人皇王遣使求见。父亲立即停止练习，转入帐内。兄弟交下弓具随同，没有特设的见习或旁听仪式。

**本场改变：**读者看见少年在家中的位置、身体局限与兄长的可靠；军政危机打断了原本平常的父子相处。

### 第三场：急使到来，先让读者听明白求援

**地点与人物：**中军帐；三赵、耶律倍的来使、一名实际负责文书或核验的属员。少年在兄长侧后，未与主事者平等议策。

**消息次序：**来使持求援书而至，疲惫、带伤的状态先于背景说明。父亲辨其身份与求援缘由；兄长问所在地、随行人数、伤者和追骑；属员据来信记下或核对道路。亲兵另催侦报，保留独立验证。

**读者在本场必须获得的信息：**

1. 耶律倍是阿保机长子、原太子，人皇王是他的称号。
2. 契丹灭渤海后改置东丹，命耶律倍主持；卢龙人物习惯沿称渤海。第一次交代后，本场谈国名尽量保持一种称法，避免来回跳换。
3. 述律太后支持耶律德光继位，耶律倍此后受到猜忌与监视，现为自己和随从求援。陆路追逃属于小说改编。
4. 来使代表耶律倍，不能让读者误认为是耶律德光派来的国使。

**可采用的说明口径：**“渤海被契丹吞并后，改为东丹。阿保机的长子耶律倍受封人皇王，主持其国事。卢龙人说起那里，仍常沿用渤海的旧称。”此为短说明的内容标准，落笔时可拆入相邻段落，不要求照句照抄。

**少年发言：**只有在使者说及伤者、离散随从等具体情况后才问一句。他的信息不超过刚听到的内容，不抢在父兄前归纳国策。

**本场改变：**一个陌生贵胄的逃亡变成赵家必须决定是否介入的事情；少年开始把棋桌上的“能不能救”联系到眼前活人，但正文不代他点题。

### 第四场：父亲决断，兄长执行，少年得到有限的责任

**讨论范围：**来使暂退治伤，内部判断由父亲、兄长与属员完成。侦报补足行动依据，避免仅凭一封求援书就出兵。

**赵德钧：**明确接纳会得罪契丹主和述律太后，权衡耶律倍的政治价值、后唐朝廷可能的支持与卢龙实际承担的风险；决定是否接应、奏报，并留足边防。请旨不能消除契丹的敌意。

**赵延寿：**提出接应力量、道路、撤回和停止追击的条件。他承担行动风险，不只负责执行弟弟的巧计。

**赵延祚：**不提出完整的请旨、分担粮饷、限制借兵等政策。他关心随从是否包含在接应范围内；若再开口，只请求跟着有经验的人办一项城内准备事务。父亲可以明确其职责边界，不授予独立调兵或代表赵家对外许诺的权限。

**分歧不能靠降智制造：**父兄已考虑伤者，限制来自兵力、运送条件和对本方军士的责任；少年希望再多保全一些。扩大安排须有真实资源与批准，不因多写几个字就自动解决。

**章尾：**以回信封定、兄长领命出发收束。少年留在城内，接下一项具体责任；关外的人尚未救回，下一章须回答接应能否赶上、承诺能否兑现。车辆被褥只写影响行动的缺口与安排，删去重复点数、重复确认。

## 三、第一次回收：太行李微对弈

1. 赵延祚因自身事件进入太行，与李微的接触有独立目的；李微围绕自己的棋局与他试下变化，不是专程给少年上一课。
2. 对弈中出现茶棚局部棋形的变种。方位、外围配置可以变化，但关键关系一致：小块尚可救，救它会连续失去主动，外围要点因此落入对手之手。只保留经核验后确实对应的差异，不机械复制整盘。
3. 少年起初仍沿旧思路救棋，李微正常应对，将后续代价下出来。少年由“这里为什么熟悉”逐步认出茶棚那一手。木疤只帮助记起旧位置，新棋盘不需要同样的木疤。
4. 少年主动提出复盘或另推一支，尝试老兵原先准备走的弃子。通过对方不同应法，确认弃子在这个局面里才是最好解，并回头核实茶棚旧局也成立。前段用一笔交代他保存旧谱，不凭空增添茶棚中未出现的棋子。
5. 将这段辨认与复盘放在同一场连续的棋局戏里，先完成基本认知，再推进其他秘密或外部冲突。避免棋理、历史讲述和战斗同时交叉，使读者再次失去线索。
6. 到此完成的是对旧棋的重新理解。后续面对有姓名、有关系的人，他仍可能努力寻找全部保全的办法。真正由他选择牺牲其他人、承担责任的变化，留给后段现实抉择。

李微有自己的牵挂与难解之局，不知茶棚往事，也不成为史继演布局的传话人。此次局部回收不等于赵延祚已经解开李微的全部心结或整个遗局，更不自动替代李微原有人物线。

### 第二次回收：嵩山，史继演榻边的原局

赵延祚已经经历主动牺牲他人的现实选择，再在史继演榻边看见当年茶棚的棋局。棋子停在他当年接手前的位置，配合史继演持黑、手指虚划圆等已埋动作，使他重新辨认茶棚中的观察者。棋盘可以换，不能仅凭一道木疤认定身份。

此时他已在李微处推过变化，故不再安排史继演从头讲解。让赵延祚自行续下老者原拟的一手，再由两人的反应与少量对话触及已经付出的真实代价。史继演不能替他的选择赦免责任，也不以解棋正确宣布他已经合格；赵延祚必须保留具体的未了责任或后续行动，使回溯通向赵则平的身份变化。

二老身份可以由棋局、旧动作与重逢逐步对应，具体双簧机制及史继演深层政治动机仍保持隐藏。不得因此把全程营救及少年经历都倒写成史继演一人安排。

## 四、称谓与注释执行

| 对象／场合 | 本版用法 |
|---|---|
| 卢龙人物沿用旧国名 | 渤海；首次出现时在正文解释与东丹的关系 |
| 正式说契丹所立政权 | 东丹；不无故与渤海交替 |
| 赵家谈耶律德光 | 契丹主，必要时用全名 |
| 赵家谈述律平 | 述律太后 |
| 赵家向使者谈耶律倍 | 人皇王、你家大王 |
| 赵德钧当面待耶律倍 | 大王 |
| 耶律倍部属称自己的主君 | 王上、大王 |

保留章末脚注并重新核对注号。新增或调整“渤海／东丹”的解释，注明史实年份与小说改编；不在注释揭露二老身份、棋局答案或后续结局。

## 五、必须联动的旧稿

- **序章第二版：**替换整盘获胜结尾、召回理由、父子入帐和少年大段议政；补弓马场景及国名称谓说明，调整章尾出发者与任务归属。
- **第一章接应：**若少年留城，重新分配现场视角和获知信息的路径；不能继续无解释地让他与兄长同时在关外。其后接触耶律倍另由行动结果带出。
- **第二章招揽：**撤去“今日输了半目”“只肯输半目”两处成熟哲学，保留暗中接触和《围棋十诀》的作用。只回认被观察，不提前解出茶棚最优路线。
- **太行草庐段：**重点重写旧第六章开局“主动弃掉仍可救的一块、得到李微认可”的顺序，改为旧习受阻、识出变种、主动复盘，避免旧稿又把他预设成早已成熟的人。章节编号随重构调整。
- **最终选择与嵩山收束：**前者完成真实责任选择；后者以史继演榻边原局作第二次回溯，结合身份辨认和选择后尚未了结的责任，不重复太行棋理解答。

## 六、落笔前检查

初读者应能明确三赵关系、世子身份与军中实权的区别、人皇王是谁、为何求援，以及接纳为何危险；兄弟必须先有真实的亲近，少年体弱不等于愚笨或无用。

棋局原型与李微局的变体尚须实际落谱核验，尤其检查对手不吃弃子时的结果。不先写死未经验证的坐标、目数和强制应手。

叙事年份继续待全书统一。旧稿926年、史实927年继位与930年南来之间的差异已有记录，本提纲不以补注代替解决年表问题。

本轮据此另存第三版序章正文；旧稿保留。后续章节、人物设定与全书年表仍待逐章重建，本次只向全局文档增补新分支进度与伏笔状态，不将未写出的回收标为完成。
