# 第一章试稿03调整落实与核验记录

本轮按作者“先讨论再整改”完成讨论后，依据“开始调整”执行。当前正文转[试稿03](<%E7%AC%AC%E4%B8%80%E7%AB%A0_%E9%A3%9E%E9%9B%AA%E6%97%A0%E7%97%95_%E9%87%8D%E6%9E%84%E8%AF%95%E7%A8%BF03_2026-10-13.md>)，[试稿02](<%E7%AC%AC%E4%B8%80%E7%AB%A0_%E9%A3%9E%E9%9B%AA%E6%97%A0%E7%97%95_%E9%87%8D%E6%9E%84%E8%AF%95%E7%A8%BF02_2026-10-13.md>)与01均保留作对照。全章仍为高崇岳视角、出窑至归撤五场，框架V3结构沿用；本轮完成整改不等于作者已审定全章。

## 一、已确定并落实的口径

| 讨论结论 | 正文／小札落实 |
| --- | --- |
| 先讲清天龙八部是什么 | 出窑首次师承说明处，写明这是天雄寺收藏、传承、依佛门护法八部命名分列的武学体系。高所学天众敬属于天部；择路处只展开已学感知，不再重复定义 |
| 八部共源天雄寺 | 三夜叉与高同出一寺，所学属于八部中的夜叉部。撤去“在寺外自成一支／外围分支”作为当前稿件的归属解释，分别交代传承来源与效命对象 |

| 无名业风是门路 | 按作者本轮用字“无名业风”与门路定位，正文写三人所修，小札记“门路：无名业风”；不称武学总纲。设定卡同步，旧资料“无明”留作历史检索别名，不自动沿用旧释名 |
| 王正月暂不提 | 当前正文与读者小札暂隐名称，不另列条目。反杀仍写感知先机、斫非沿中线正斩及身体代价；既有剑法设定保留，式次问题不在本轮定序 |
| 小札逐行“文字：文字” | 五组：天众敬、夜叉部、斫非、银蛟与鸣镝、碎玉劲。每行一个字段，不再把多种作用合成大段散文 |
| 三路武技齐列 | 夜叉部下三人各列名讳、所长、武技、兵刃，风无相／地无常／水无形同级呈现。三人共同所修门路与各人专擅分开 |

## 二、代理自查发现的其他问题与处理

| 原问题／证据 | 本轮处理 |
| --- | --- |
| 序章昨夜写信、当日送达，02却说“昨夜王书已经送到” | 改为“王书已经送到”，不另编隔夜停兵，也不增未经核定的时辰 |

## 三、小札与认知边界

天众敬只记正文已出现的两种感知，未列后续境界与总数。夜叉部三人的完整名字、武技、兵刃均已有正文对应。扇毒注明“据高崇岳所言”；碎玉劲伤势注明“据耶律倍所言”。铸材、具体毒物、暗器机关、伤势施劲者及解法仍不详。

王正月暂隐后，不以问号条目暗示将来必有某一招。天龙八部的八部数量在本轮正文定义中公开，不以此推导天众敬境界数量或任何尚未出场门路。刀剑、弓枪的条目仍采用“兵器小札”，不并入心法体系。

## 四、设定同步范围与保留项

本轮最小同步天雄寺人物卡、夜叉部武学卡、组织总览与设定进度汇总：明确八部共同寺源、三人所修门路、当前称名与三路武技层级。天雄寺人物卡同时将原“心腹伴读”澄清为“伴读其子、本人为记名弟子”，与既有高崇岳人物卡及本章已明确的关系一致。无名业风指这三人的门路，不扩为整个天龙八部或夜叉部的总纲。

既有阿修罗部外来残卷等背景未改。“出自天雄寺”在本轮指小说中共同收藏与传承来源，不扩写为全部由耶律倍原创、全部已经完整。原版各章、序章V6和试稿01／02未改。相关旧档仍存在的年份、年龄与王正月序号不在本轮统一。

## 五、后续接口

RF01–RF14的兑现与待收责任延续。追杀回文只再次提醒前文已公开的监守与追袭，不等于政治后果已回收，也不等于碎玉劲伤源已揭。
