# 晚唐五代中枢与节镇任免（920-950）

> 说明：围绕 920-950 年间的中央宰执和重点节镇节度使，按阶段列出时间、人选、官职、前任／后任、变动原因以及可用于小说的政治张力。

## 一、主要中枢与宰执换血

- **923年5月｜后梁 → 后唐**：李存勖取代后梁末帝朱友贞登基，接替的是原后梁的宰臣和枢密，自己重用豆卢革、郭崇韬等老面孔担任同平章事与枢密使，试图让唐姓和旧臣交替压住乱局。前任是失去军心的后梁中枢，后任则是他自己亲信；背景原因是必须快速制造“唐室再兴”的合法性，张力来自旧臣与边镇军权之间的双面忠诚。
- **926年4月｜李存勖 → 李嗣源**：李存勖死于兵变后，李嗣源接管皇位，并起用冯道等善于收束局面的老臣稳住中书与枢密。前任是李存勖一朝的宠臣与近信，后任则是李嗣源更倚重的务实官僚；背景原因是必须用经验型人物压住仍在蠢蠢欲动的节度使，张力在于皇帝的合法性和兵权之间几乎没有缓冲。
- **934-936年｜李嗣源→李从厚→李从珂**：李从厚被废，李从珂继位后仍惦记河东节度使石敬瑭，刑杀他亲信，激起石敬瑭与契丹结盟反叛，前任是李从珂的宦官同僚，后任是石敬瑭所建的后晋皇帝。背景原因是节度使不满被中央挤压，加上皇帝对“藩镇”忠诚度的怀疑，张力是皇帝要在葬送将领和防止割据之间选路。
- **936-947年｜后晋建国期**：石敬瑭依靠辽兵登基，取代李从珂；他让赵莹、桑维翰、冯道等更迭宰执，交替掌握中书门下、枢密使等要职，接替晚唐以来的官僚。前任是李从珂的旧臣，后任是专心讨好辽人的石敬瑭与后继的石重贵；背景是需要辽国军队保驾护航，张力是宰执每天在朝纲与辽礼之间跳舞，既怕辽人不满，又怕自己被节镇的武夫挑动。
- **947-950年｜后晋 → 后汉 → 少帝掌权**：石重贵败亡后，河东的刘知远以“北汉复唐”名义继位，接替的宰执是苏逢吉、苏禹珪、窦贞固、李涛、杨邠这批操盘皇权的绿叶。前任是后晋沿用了多年、与辽亲近的宰相，后任是刘知远死后被刘承祐亲近者替换的几人；背景是辽军未撤、少主年幼，张力在于摄政集团与幼主的矛盾，最终在 950 年的“诛杨事件”被少主用靠近的词臣取代并引发军人反扑。

## 二、重点节镇节度使换位

- **河东/并州**：自李克用父子起，河东就是中枢与节镇的交汇点。李存勖用此路夺取后梁，后被李嗣源继任；后又转由李从珂掌握，936 年石敬瑭在此位发动叛变（前任是李从珂的亲信，后任是石敬瑭），随后石敬瑭死后由石重贵继位；947年刘知远兼并河东（前任是后晋，后任是后汉皇帝），延续使它的节度使名号与帝位互为跳板。背景是该地士族与军阀质疑帝号，张力在于“河东人”既是新皇登基的柱石，也是中枢最大的隐性威胁。
- **天雄/天雄府（天雄、冀州一带）**：950年5月，刘承祐为了压制杨邠等摄政，令郭威镇守天雄（前任是天雄指挥使，后任是郭威），并在其家眷被杀后让郭威怀疑皇位。当廷尉上演“诛杨”后，郭威成了被逼出手的节度使。背景原因是皇帝无视先前对边防军的包容，张力在于一位手握重兵的晋冀节度使被逼与朝廷断层，最终在 951 年起兵，改变了五代格局。
- **“十六州”与辽的割让**：石敬瑭投靠契丹换取皇位时把河洛以北的十六州交出，前任是后唐、后晋自身战守的镇将，后任是契丹统治，背景是缺乏兵力撑持的后晋求援，张力是化身“契丹护国”的节度使在国内也成为可疑的双面人物，随时可能引火烧身。

## 三、小说张力提醒

- 920-930 年：新皇以唐姓自诩、旧臣与新军双重调整，宰执每天都担心“背后是战功靠山”把他们挤下去。（如豆卢革、郭崇韬被迫在骄横的李存勖和疑心的节度使之间讨好）
- 936 年：李从珂的疑心把河东将领石敬瑭推向辽国，形成“宋辽廷前线”的极端张力；他替代的不只是皇帝，还有整个中枢和边镇的根基。
- 950 年：摄政杨邠与新皇斗法，杨死后郭威在天雄数十万兵马前被逼不得已起兵，意味着节度使既是朝廷的靠山也是随时可能反扑的钉子，适合描写“朝野内斗引爆外患”的节奏。

## 资料线索

- Later Tang（英文维基）描绘了李存勖被节度使与宦官共同掀翻、李嗣源继位以及石敬瑭借辽兵反叛的脉络，提供了 920-936 年间中枢更迭的背景。
- 同平章事（中文维基）列出了 923-950 年间的同平章事与枢密使人选，方便核对宰执更替的顺序。
- Later Jin（英文维基）说明石敬瑭与契丹结盟、后晋成为辽属国、十六州割让等关键事件，为 936-947 年的中枢与节镇关系提供依据。
- Later Han（英文维基）记录了刘知远作为并州（并州即河东/并州）节度使起兵建国，说明后晋覆灭后节度使掌权的直接通路。
- 杨邠（英文维基）与慕容彦超（英文维基）共同记载了 950 年的摄政集团与刘承祐之间的权力斗争、杨邠被诛以及朝廷对郭威家庭的屠戮。
- 赵匡（柴荣）相关条目提到 950 年郭威被授予天雄节度使并在家属被杀后起兵的经过，说明节度使处于朝廷与军队之间的爆炸点。
