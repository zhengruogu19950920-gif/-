## 一、执行规则

### 1. 冲突裁定
- 本文件与旧全局文件、旧聊天纪要、旧章节框架、旧格式说明如有冲突，以本文件为准。
- 旧第七章《紫气东来》框架文件仅作历史归档，不再作为正文起草依据。

### 2. 写入前必做
- 确认当前章节编号、标题、状态、场域、视角与最新锁定设定。
- 确认近期是否存在拆章、顺延、改题、地名修正、人物口径修正等决议。

### 3. 写入后必做

## 二、项目定位

- **作品名称**：`《寒枰》`
- **作品性质**：`《燕云歌》主线（944-947年）之前传`
- **时间跨度**：926-928年
- **主角**：赵延祚，后为赵普，字则平
- **核心弧线**：从卢龙世子走向嵩山门人，形成“势孤取和，只负半目”的实用主义哲学
- **审美方向**：克制、含蓄、留白、隐喻式命名
- **章节结构**：⚠️ **过时待修**。旧口径为“序章 + 10章”，但第八章《一响》已前置并完成高崇岳与赵延寿的夜战功能，洛阳之后章节分工需重新拆定。
- **字数控制**：旧档曾出现“约9万字”与“约15万字”两种口径，现统一不作硬约束；后续以完整完成洛阳局、狻猊/霸下揭示、赵延祚最终武力对抗与入嵩山收束为先，不再受“序章 + 10章”硬约束。

## 三、统一口径

### 1. 时间线与年龄
- 926年事件中：赵延祚15岁，高崇岳16岁，赵延寿22岁，刘赟18岁。
- 928年前传主线中：赵延祚17岁，刘赟20岁。
- 926-928年为前传时段；944-947年为《燕云歌》主线时段。

### 2. 人物与信息口径
- 高崇岳于926年幽州结识赵延祚，并于同年加入嵩山派。
- 赵延祚在928年加入嵩山时，并不知道“桑维翰即嵩阳先生”这一双重身份；该真相在主线中逐步揭开。
- 赵延寿前传中的核心外观动机是“保护弟弟”，真实内核是取而代之；其扭曲加剧的重要起点是926年误读《纳贤簿》残卷。
- 刘崇不是刘赟兄长，而是其名义上的父亲，也是“造剑者”。
- 恒山派肉身修持承自苦行一脉，门中修心与念佛口径兼受净土宗浸润。

### 3. 当前章节推进口径
- 旧第七章《紫气东来》已经拆分为两章：
  - 新第七章：掉举（刘赟章）
  - 新第八章：一响（太行陉大口道战斗章）
- 当前第七、八章相关场域统一使用**太行陉大口道**。
- 南下路线统一写作：
  - **出太原南门外，避官道，斜折东南，入榆次县界，再向昭义军潞、泽方向下去。**
- 第七章《掉举》当前锁定为六节结构：
  - **水声 / 人声 / 无声 / 旧声 / 杀声 / 余声**
- 第七章 S4 固定改为**第一人称**，S6 止于**刘赟抵达废驿、跨过门槛入内**；旧版废驿内声响口径已废止，不再作为第八章待回收谜底。
- ⚠️ 旧口径废止：萧鲁直不再作为“必须活着且不解释存活”的气口。洛阳段需与大召赟一起正面回收，并可安排死亡退场，与赵明之死形成互文。
- 新第八章结尾锁定为**切赵延寿视角**。

> ⚠️ **后续章节分工待重修**：旧第九章/第十章规划已不再可靠。第八章已完成“高崇岳截赵延寿异劲 / 高赵夜战预热”的一部分终点功能，后续洛阳段需重新规划。当前临时新口径：后续主要武力终点暂考虑由**赵延祚 vs 张瓘 + 赵延寿**承担；狻猊可考虑在张瓘第二次出场后完整揭示，并借狻猊身份反推霸下即赵延寿。以上为待讨论口径，尚未正式定稿。

## 六、创作纪律

### 1. 视角纪律
- 每章视角人物必须明确。
- 全章不得越出该视角的感知边界。
- 视角人物不知道的事，不得以旁白或直接内心形式补出。
- 允许读者通过视角人物“感知到但无法解释”的细节自行推断，但不得由旁白替读者说破。

### 2. 冰山原则
- 禁止直接贴人物性格标签或直接说明行为动机。
- 性格与动机只能主要通过以下方式呈现：
  - 身体反应
  - 对话中的省略与停顿
  - 行为与预期之间的落差

### 3. 算计者的情感处理
- **赵延寿**：允许出现“算计失控”的情感溢出，那是其人性裂口。
- **赵延祚**：前传阶段允许真实情感存在，但必须仍然遵循冰山原则；随着前传推进，其情感出口应逐渐收窄。

### 4. 赵普身份的叙事处理
- 前传必须保留“他本可以不同”的真实可能性。
- 张力来自“IF感”与“宿命感”并存。
- 禁止由旁白或人物直接宣判其命运走向。
- 每一步走向赵则平、走向赵普的代价，都应在文本中留下痕迹。

### 5. 信息克制分层
- **第一层**：阅读时可识别的机关与伏笔。
- **第二层**：需要主动拼合才能发现的结构。
- **第三层**：不在正文中直接点破、只存在于读者过度解读中的不可见层。
- 写作时必须保证第一层清晰、第二层严密、第三层不被点破。

### 6. 历史注释策略
- **A类必注**：不注则正文逻辑断裂。
- **B类可选注**：注了更深，不注也能读。
- 早期章节可兼用A/B类帮助建构世界；随着推进，逐步减少B类，让读者依赖既有认知自行推断。

## 七、格式写入规范

### 1. YAML Frontmatter
- 草稿文件必须在顶部包含标准 YAML 属性区。
- `characters` 字段必须使用标准 YAML 列表，不得写成 JSON 字符串。

```yaml
---
tags:
  - 前传/草稿
chapter: 第X章
title: 章节标题
characters:
  - "[[04-赵则平]]"
  - "[[14-赵延寿]]"
status: 草稿完成
---
```

### 2. 标题与时空背景
- 正文开头需标明章节号与标题。
- 标题下方紧跟一行加粗时空背景。

```markdown
# 第一章：飞雪无痕

**后唐天成元年（926年）春，军都陉**
```

### 3. 分节与诗词排版
- 章节内部若需分节，使用四级标题：`#### 第X部分：小节名`
- 诗词、判词、定场诗使用加粗并按句换行。

### 4. 章节结束语
- 正文结束后，空一行，使用加粗括号标明章节结束。

```markdown
**（第一章 完）**
```

### 5. 考据与脚注
- 注释区必须放在正文结束语之后，以 `---` 分隔线与正文隔开。
- 标题统一使用：`**【考据小注】**`
- 每条注释必须使用全角冒号。

```markdown
---
**【考据小注】**

[^1]: **军都陉**：太行八陉之一，即今北京居庸关一带。
```

## 八、镜头绘制技巧

### 1. 适用场景
- 同一物理空间内，三人及以上同时行动、且各自带有独立目标线的高密度场景。
- 典型用法：战斗、对话、叙事、解谜同时推进的复合段落。
- 典型案例：第六章草庐内多线并行场景。

### 2. 核心原则
- 多线并行场景不能直接写，必须先出分镜。
- 大纲只说明“发生了什么”，分镜才说明“第几秒、谁在哪里、做了什么、说了什么、看到了什么”。
- 不先做分镜，文本很容易退化为“轮流独白”，即一次只剩一两个人在场，其他人物像被叙事临时撤下舞台。

### 3. 常见失败模式
- **轮流缺席**：连续几段只剩部分人物在场，其他人完全消失。
- **空间跳跃**：人物位置突然变化，读者不知道他怎么过去的。
- **视角穿越**：出现视角人物本不可能知道的信息或他人内心。
- **棋战割裂**：并行线被写成两场互不影响的独立戏。
- **节奏匀速**：整段没有快慢变化，读者感受不到时间加速或骤停。
- **信息过载/真空**：某些段堆满设定，某些段几乎没有有效信息。

### 4. 六件工具
- **时间切片**：按一到两次心跳为单位组织场景，而不是按“事件段落”组织；每个切片中，在场人物都应有动作或状态。
- **节拍器**：选一项可重复、可感知、频率可变化的动作做全场共享节拍，如落子、出招、停顿、钟声。
- **空间平面图**：动笔前先画人物初始位置、关键物件、移动轨迹与大致距离，防止物理错误。
- **信息释放检查表**：逐条标注一段场景中的关键信息由谁、在何时、以何种方式得知，防止视角穿越。
- **叙事节奏总览表**：对需要逐步抛出的长线信息分阶段拆层，避免一段过满、一段过空。
- **物理时间单位**：用心跳、呼吸、落子、出招等单位控制阅读速度，实现“慢 - 快 - 更快 - 骤停”的节奏变化。

### 5. 标准工作流
1. 明确有几条线、每条线的目标是什么。
2. 画空间平面图。
3. 做信息释放检查表。
4. 如存在长线叙事，再做节奏总览表。
5. 用时间切片写出分镜表。
6. 选定节拍器，检查每个切片里所有在场人物是否都“还在场”。
7. 标注关键节点的物理时间单位。
8. 对照失败模式清单逐条检查。
9. 开始写草稿。
10. 草稿完成后再次复检失败模式。

### 6. 适用边界
- **适用**：同场多人物并行、战斗与解谜交织、强视角限制下的信息编排。
- **不适用**：跨空间蒙太奇、多地点同时发生的戏、单人独白为主的静态场景、全知视角叙事。
