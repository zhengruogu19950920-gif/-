## 当前重构入口

序章第六版为暂定稿，对应提纲 V5；第一章目前是重构框架 V2，尚未写成新正文。其他章节的原版状态不代表完成本次重构。具体口径见 [前传全局总纲](<%E7%87%95%E4%BA%91%E6%AD%8C/%E7%87%95%E4%BA%91%E6%AD%8C%E5%8F%8A%E5%89%8D%E4%BC%A0%E5%B0%8F%E8%AF%B4%E5%88%9B%E4%BD%9C%E9%A1%B9%E7%9B%AE/02-%E8%B5%B5%E5%88%99%E5%B9%B3%E5%89%8D%E4%BC%A0/00-%E6%80%BB%E7%BA%B2%E4%B8%8E%E8%BF%9B%E5%BA%A6/00_%E5%85%A8%E5%B1%80_%E5%89%8D%E4%BC%A0%E6%80%BB%E7%BA%B2_%E6%A1%86%E6%9E%B6%E6%8C%87%E5%BC%95%E4%B8%8E%E8%BF%9B%E5%BA%A6.md>)。

## 本地使用

在 Obsidian 中将 [燕云歌目录](<%E7%87%95%E4%BA%91%E6%AD%8C/README.md>) 作为库打开。浏览时优先使用各目录的 README；文件原标题、版本编号和日期已保留。
